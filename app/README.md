# 🚀 Next.js Task Manager

A modern, highly responsive To-Do application built using the latest **Next.js App Router** framework, tailored with strict **TypeScript** architecture, and styled elegantly using **Tailwind CSS**.

## 🛠️ Tech Stack & Core Tools
*   **Next.js (React Framework):** Powers the optimized page routing and component layout.
*   **React State Hooks (`useState`, `useEffect`):** Manages interactive user states like adding, filtering, and checking off tasks.
*   **Tailwind CSS:** Provides clean utility classes for mobile-responsive card UI layouts and layout transitions.
*   **Web Storage API (`localStorage`):** Synchronizes tasks directly to the browser environment so tracking data persists safely across page updates.
*   **TypeScript:** Enforces type safety (via strict interfaces) to minimize syntax execution errors.

## ✨ Key Operational Features
*   **Dynamic Task Management:** Real-time adding, task status toggling, and task clearing.
*   **Multi-Tier Filtering:** Interactive sorting filter modules to cycle views seamlessly between **All**, **Active**, and **Completed** items.
*   **Live Metrics Display:** Built-in calculation modules displaying real-time counters of active remaining tasks.
*   **Data Persistence:** Local web retention logic that safeguards inputs from data wipes on accidental browser refreshes.

## 🚀 How to Open and Run
1. Clone or import this repository structure.
2. Install standard dependencies:
   ```bash
   npm install
   ```
3. Run the local Next.js development server environment:
   ```bash
   npm run dev
   ```
4. Access the web interface securely at `http://localhost:3000`.
